# 商品库存状态、MinIO 上传与界面优化设计

## 目标

完成以下五项优化，同时不改变既有订货、零售购买、库存冻结和文件访问的业务边界：

1. 区县代商品详情中的“向平台订货”按钮按平台商品总库存显示可用或无货状态。
2. 为 `JkBizConstants`、`JkRelationPermissionCodes`、`JkV31PermissionCodes` 增补可维护的说明注释。
3. 将 MinIO 作为平台通用上传提供商接入后台文件上传配置，并复用基础连接配置给九州康私有附件。
4. 在零售购买数量选择后，清晰引导用户点击“加入购物车”或“立即购买”。
5. 优化首页底部公告的文字留白与层级。

## 业务边界

### 平台订货与零售购买

- “向平台订货”仅面向拥有既有平台订货权限的区县代，跳转到已有的订货建单页面。
- 该入口与商品详情的零售购买数量无关；购买数量只服务于“加入购物车”和“立即购买”。
- 按选中商品规格的平台商品总可售库存控制订货入口：库存大于 0 为主题色可用态；库存为 0 为灰色，并在点击时提示“当前商品暂无库存”。
- 本次不改变库存扣减时点。现有流程为：创建订货单仅保存订单；付款审核通过时冻结平台库存；平台发货时将冻结库存出库；区县代确认收货时入库。
- 现有审核冻结与发货出库仍保留库存不足保护。本次不将库存冻结提前至商品详情或创建订单时。

### MinIO

- MinIO 是通用上传方式，与本地、七牛、阿里云 OSS、腾讯 COS、京东云并列。
- 通用上传（商品图片、素材库等）选择 MinIO 后使用配置的公开访问域名或 CDN 域名生成访问地址。
- 九州康私有附件复用 MinIO 的 Endpoint、Bucket、Access Key、Secret Key 和 Region，但继续通过现有鉴权下载接口读取对象，不暴露私有对象直链。
- 切换上传提供商只影响之后上传的文件；历史附件保留其原存储地址和读取方式，不做迁移。

## 设计方案

### 1. 商品详情库存状态

商品交易视图提供当前规格的平台可订货库存和不可用原因。前端将它用于区县代的“向平台订货”按钮：

- 有库存：健康绿主题色，点击进入原订货建单页。
- 无库存：灰色状态，仍接收点击以展示明确提示，不跳转。
- 交易身份或权限不满足：沿用现有权限不可用提示。

零售购买操作独立保留。用户变更数量后，在“加入购物车 / 立即购买”上方显示“已选 X 件，请选择购买方式”，可用一次轻量高亮加强注意力；不改变数量数据、购物车参数或立即购买参数。

### 2. MinIO 后台配置

在“系统设置 → 文件上传配置”新增 MinIO Tab 和上传类型。配置字段为：

| 字段 | 说明 |
| --- | --- |
| Endpoint | MinIO/S3 兼容服务地址，含协议与端口。 |
| Bucket | 用于新文件的对象桶。 |
| Access Key | 服务访问凭证。 |
| Secret Key | 服务密钥，回显时脱敏。 |
| Region | S3 签名区域，默认 `us-east-1`。 |
| 文件前缀 | 新对象的统一目录前缀，可为空。 |
| 访问域名/CDN 域名 | 通用上传文件对外访问的基础地址。 |

后台提供“测试连接”操作，仅验证连接、Bucket 权限与写入能力；测试对象使用专用临时前缀并在完成后删除。保存配置前校验 Endpoint、Bucket 和凭证必填，访问域名在通用上传选择 MinIO 时必填。

服务端新增 MinIO 上传提供商并纳入现有通用附件上传、CDN 地址解析和上传类型接口。九州康私有文件服务改为从系统配置读取同一组 MinIO 基础参数，保留私有访问鉴权。

### 3. 常量注释

三个常量类添加类级职责说明，并对每个逻辑分组添加简洁注释：

- `JkBizConstants`：角色、账户类型、状态、业务事件、系统配置键等；
- `JkRelationPermissionCodes`：关系链、额度、绑定与后台操作权限；
- `JkV31PermissionCodes`：v3.1 管理端权限域。

不修改常量名、字符串值或权限编码。

### 4. 首页公告

公告底部模块保留数据、标题和点击行为。通过增加标题与正文间距、细分隔、正文行高和底部内边距改善可读性，避免正文紧贴顶部。

## 错误处理与验证

- 订货入口在库存为零时不导航，并提示无货；付款审核阶段保留现有库存冻结失败处理。
- MinIO 测试或上传失败时返回明确错误，不保存不完整配置，不返回伪成功地址。
- Secret Key 不在接口或页面明文回显。
- 测试覆盖：库存为零/有库存的按钮状态，数量提示的独立性，MinIO 配置校验与上传路径，私有附件读取，以及常量类编译。

## 非目标

- 不提前冻结或扣减平台库存。
- 不增加代理专属库存、配额或库存迁移。
- 不迁移历史上传文件。
