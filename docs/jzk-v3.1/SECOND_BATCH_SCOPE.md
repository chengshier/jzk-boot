# 九州康 JZK V3.1 第二批：业绩、经营与佣金闭环

本分支基于 `feat/jzk-v3.1-phase1-closure`，不代表第一批真实环境已经验收。

## 已实现范围

- 独立业绩账本 `jk_performance_record`；
- 线下经营收益账本 `jk_operation_profit_record`，收入性质固定为 `OFFLINE_REALIZED`；
- 线下销售主单、商品、审核日志及真实库存出入库；
- 调拨批次加权成本、价差与经营毛利；
- 创客、合伙人、区县代理统一佣金规则字段；
- 规则草稿、试算、审核发布、停用和时间边界；
- 规则叠加/互斥、单笔封顶和匹配日志；
- 没有已发布规则时只记录业务、业绩和未命中日志，不生成可提现佣金；
- 线上零售退款、线下销售退货、调拨退回分别冲正业绩、经营收益和佣金；
- 新佣金继续兼容现有 `PENDING_SETTLE -> SETTLED` 结算主链路。

## 默认关闭

第一批初始化的创客、合伙人、区县代理模板仍保持关闭。只有补齐比例/金额、受益人来源、计算基数、生效时间，并通过发布接口后才允许真实入账。
